# PharmaScan Care

**Team:** PharmaScan  
**Competition:** Tencent Cloud AI CAN DO IT Hackathon Singapore 2026 — Healthcare Track, Challenge 2  

A voice-first personal medication companion for medication information, visual-candidate matching, regimen records, self-reported dose tracking, and longitudinal care support.

Read [`PROJECT_BRIEF.md`](PROJECT_BRIEF.md) for target users, scope, limitations, security requirements, and planned tools.

## Current assets

- Team-reported independent Stage 2 pill candidate API: https://davidpansx-pharmascan-api.hf.space/ui/ — endpoint schema and availability **not verified** in this repository.
- Stage 1 detector: **not implemented**.
- Frontend, backend, database, agent: **not implemented**.

1. Read `docs/WORKBUDDY_START.md` and run the first Ask session.

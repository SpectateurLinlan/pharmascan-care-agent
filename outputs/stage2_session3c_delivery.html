1. v0.4 → v0.8 的真实差异

边界原实现 / 历史问题现在的处理
快照与历史旧工作路径被删除；0.4 embed/match/identify/scan 的 200 schema 实际为 {}。从 local Git HEAD 恢复真实 0.4 字节；保留 owner 的 0.8。追加纠正“无 similarity 已获契约确认”这一旧日志，无删改历史。
Embedding缺元数据时回落配置，裸向量缺少空间证据。必需 dim/model/space/preprocess/normalized；实际 256 长度、finite 数值、声明维度与范数核对。256 不由 OpenAPI 数组长度约束保证。
Match旧猜测 pills 形状；不映射 score。按 results/similarity/closest/runner_up/threshold/margin 映射；单个 typed EmbeddingResult + typed gallery，版本一致。相似度不是概率；margin 不是 top1/top2 实测差。
Detect / Scan可能误解坐标或 provider count。像素 xyxy 转 x/y/w/h；Scan 的 detection 是嵌套对象；不伪造 box score。provider_count_reliable 与 app count eligibility 分开，自动计数始终关闭。
Identify 请求响应 fixture 测试未捕获错误的 image 上传名。修复为必需 images 数组的一份 multipart part；真实 MockTransport 请求测试覆盖。其他受支持图像端点为 image。当前 app top_k 上限10，provider schema 上限20。
Read-label产品识别与患者疗程容易混淆。公开 SourceExtractionPort；产品身份与 Printed 疗程证据分离，保留 value/line/null/omission。不推断 dose/frequency/time/duration，不激活或查写库，不再造 OCR。
外部 JSON未完整依据冻结 schema 校验。基础设施验证完整 JSON Schema 再 wire projection；允许的未知外部字段忽略，缺少必需字段安全拒绝。Domain/Application 只接公开 DTO。

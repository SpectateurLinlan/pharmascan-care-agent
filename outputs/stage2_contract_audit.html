关键契约缺口与额外安全要求

  • Embedding.embedding — array<number> 无 minItems/maxItems；dim 无 const 256；256 仅为描述/运行时 model-info 的值256 维、有限数值、单位范数、normalized=true、metadata 一致；非 OpenAPI 长度保证
  • MatchRequest — queries/gallery 外层 minItems=1，内层向量无长度约束；版本字段非 required至少一个版本/space 标识、实际匹配模型与预处理及 space；不能只依赖 schema
  • Detection.boxes / ScanPill.box — PIXEL xyxy 描述，数组无四元素约束；不使用 x/y/w/h四个有限像素坐标、边界合法；count_reliable=false 不自动计数
  • ScanPill — 仅 box required、additionalProperties=true；decision/candidates 未类型化合成 scan 扩展使用完整 MatchResult；测试另验该扩展，不声称 OpenAPI 强制
  • /v1/tools 200 — schema={}，不能证明任何输出字段存在
  • /v1/pills/{pill_id}/image/{n} 200 — 描述 JPEG，但声明 application/json schema={}；未请求
  • ModelInfo.calibration / imprint — 自由对象，无内部 required；合成数据不得冒充校准
  • MatchResult.decision — match/unknown/ambiguous enum；无跨字段决策约束0.99 相似度非 99% 识别概率；合成阈值不提供临床性能证据
  • ReadLabelResponse / DocumentFields — source 默认 photo 非 required；fields/directions 可省略或 nulldirections 仅引用 synthetic Printed.value/line；缺失绝不补造用药指令
  • safety endpoints — 无 alert 不等于安全；coverage 与 source 必须保留；剂量决策属于主后端

省略与 null

detect_success.message 省略；detect_unreliable_count.message 显式 null。两者均合法但语义不同。MatchResult 的 medication_id/name/runner_up 为 required 且 nullable，不得省略。missing directions=null，不补造指令。
